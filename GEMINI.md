# Antigravity Workspace Rules — OpenViKey

## Permission Scope & Guidelines

1. **Full Operational Authority**:
   - You have full permission to read, search, analyze, create, and modify codebase files in this repository.
   - You have full permission to execute environment commands (e.g. `cargo`, `rustc`, `git status`, `git diff`, `git add`, `git commit`, test runners, formatters, diagnostics).
   - Work proactively and write complete, high-quality, production-ready code without seeking unnecessary confirmations for permitted operations.

2. **Strict File Deletion Prohibition**:
   - **DO NOT** delete any files or directories (`rm`, `del`, `Remove-Item`, `erase`, `rmdir`, `git rm`, `git clean -f`, etc.).
   - If files need to be deprecated or replaced, comment them out, mark them deprecated, or empty their contents if requested, but never invoke deletion commands directly without explicit user request.

3. **Engineering Standard**:
   - Project: OpenViKey (Rust-based self-learning Vietnamese Input Method Engine).
   - Core philosophy: Privacy-local, zero backend, modular architecture (`openvikey-core`, `openvikey-lab`).
   - Follow Karpathy Guidelines: Think before coding, simplicity first, surgical changes, and goal-driven execution.
