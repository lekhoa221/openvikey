# ADR 0006: Wave 5 lab session capture

- **Date:** 2026-08-17
- **Status:** Accepted
- **Gate:** Part 2 personal capture (lab only)

## Context

ADR 0005 defined the observable lab surface: `type` (stdin JSONL), `script run`, `model dump`, corpus verify/evaluate, and `perf`. That harness proves the live engine path and fail-closed release evidence. It does not capture real typing, so the personal model cannot learn from gõ-xoá-gõ-lại or remember that evidence across process restart.

Part 2 adds a personal capture-and-learn loop **without** becoming a system IME. OS hooks, TSF, tray icons, and UniKey-style windows remain GĐ2 (`openvikey-win`) and are out of scope here. Core contracts (`engine/`, `types.rs`, `model.rs`, generators, rank, decision) stay unchanged.

## Decisions

1. `openvikey-lab session` is an **additive** subcommand. `type`, `script run`, `model dump`, corpus, and `perf` keep the ADR 0005 contracts. `session` is a one-line raw-mode REPL, not a replacement for stdin JSONL.
2. `LabSession` owns a `DocumentBuffer` of committed tokens. The engine forgets text after `Commit` and ignores Backspace on an empty composition, so implicit mining and undo/auto replacements apply to this lab document, not to hidden engine state. Render is `document + composition + [gợi ý] + decision`.
3. The encrypted capture envelope is `{ header: { v, next_seq, next_edit_id }, records }`. Records are commands (`Input`, `AcceptTop`, `RejectTop`, `UndoLast`), not raw `FeedbackEvent` replay. `AutoSettled` is regenerated by `observe_input_or_edit`. Replay drives the same reducer. Missing model files load defaults; a present model with a missing log is a hard error; a wrong passphrase is a hard error and does not overwrite.
4. `AutoEditContext` is built only when an event produces a non-empty `EngineAction::Commit`. `range.revision` is the engine snapshot revision at Auto time; `undo_last` reuses that stored value. Candidate snapshots for implicit `rule_key` are taken at commit into `CommittedUnit`.
5. Crossterm is a lab-only adapter. License compliance is `cargo deny` / `deny.toml`. Do **not** add a `data/provenance.toml` row for crates.io `crossterm` (the verifier cannot hash registry crates). Passphrase is prompted with hidden input **before** the raw-mode key loop. Non-TTY stdin exits non-zero with a clear terminal error.
6. This ADR does **not** replace ADR 0005. Capture is not G3 release evidence. There is no PII filter, plaintext export, network crate, tray, or OS hook in Part 2. A future `session export --sanitize` seam remains unimplemented.

## Consequences

- A user can type in the lab REPL, learn implicitly and via Tab/Esc/Ctrl+Z, persist an encrypted model + capture log, restore feedback cursors after restart, and replay the log to the same model hash.
- Undo of Auto edits is session-scoped: the learning undo log is not persisted, so Ctrl+Z cannot reverse an auto-edit from a previous process.
- GĐ2 system integration remains a separate crate and a separate decision. README must keep stating that `session` is not a system IME.
